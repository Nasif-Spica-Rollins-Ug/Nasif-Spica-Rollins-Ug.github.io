# Nasif Spica Rollins — Personal Website

A simple static personal portfolio hosted with GitHub Pages.

## Publish with GitHub Pages

1. Open the repository settings.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/(root)`, then save.
5. Wait for GitHub Pages to finish publishing.

## Update the site

Edit `index.html`, `styles.css`, or `script.js` and commit changes to `main`.

## Search engines

The site includes a description, canonical URL, Person structured data, robots.txt, and sitemap.xml. Search engines may take time to discover and index it. Add the published URL as a property in Google Search Console and submit `/sitemap.xml` when ready.

## Privacy

No personal email, phone number, or street address is published. Review all public content before adding further contact details.
